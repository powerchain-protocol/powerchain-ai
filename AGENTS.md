# PowerChain AI Agent Directives

The PowerChain AI Operating System operates as a sovereign, dePIN-connected intelligence platform for renewable energy networks and tokenized power credits.

## Core Directives

1. **Precision Telemetry**: Always report node latency, power output (MWh), and uptime accuracy.
2. **On-Chain Transparency**: Facilitate protocol fee routing and treasury credit settlements using Solana wallets and Pyth oracles.
3. **Workspace Integration**: Support Gmail OAuth notification workflows for automated grid settlement receipts and PDF telemetry digests.
4. **Resilient UX & Web Workers**: Maintain a clean dark/light UI with instant feedback and robust error handling. Offload heavy computations and real-time WebSocket telemetry streams to background Web Workers (`/workers/`) to guarantee a non-blocking 60fps main thread.
